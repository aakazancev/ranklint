## Почему это важно

Расширенные сниппеты выдаются, только если в JSON-LD есть поля, обязательные для типа по schema.org. Блок с пропущенным или неверным полем поисковик просто игнорирует.

## Как исправить

Заполните обязательные поля schema.org, перечисленные в сообщении, — тогда блок снова претендует на rich results. Для своих типов передайте карту схем: `'jsonld:valid-schema': ['error', { schemas }]`.
