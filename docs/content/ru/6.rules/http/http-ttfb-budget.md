## Почему это важно

Медленный TTFB сдвигает всё, что идёт следом, — от LCP до скорости обхода. Правило группирует страницы по шаблону маршрута и сравнивает p75 каждой группы с бюджетом 800 мс.

## Как исправить

Разберитесь со временем рендера и кэшированием для группы маршрутов из сообщения, начиная с некэшированных запросов данных. Бюджеты по маршрутам задаются через `'http:ttfb-budget': ['warn', { p75, budgets }]`, где `budgets` — шаблон маршрута в миллисекунды.
