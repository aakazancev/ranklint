## Почему это важно

Краулеры без JavaScript индексируют ответ сервера, поэтому контент, появляющийся только после гидратации, для них не существует. Правило сравнивает SSR-HTML с гидратированной страницей и ждёт, что хотя бы половина текста отрендерена на сервере.

## Как исправить

Вынесите H1 и основной контент из client-only компонентов, чтобы они попадали в ответ сервера. Если часть страницы обязана рендериться на клиенте, ослабьте порог через `'indexability:ssr-content': ['error', { minRatio }]`.
